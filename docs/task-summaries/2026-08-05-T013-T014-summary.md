## T014 - 測試失敗自動修復迴圈 ✅

**實作**（`auto_develop.py`）：
- 測試/檢查失敗時自動呼叫模型，prompt 含：任務驗收標準（前 1500 字）+ 品質閘門失敗輸出（末 4000 字），要求輸出修復 diff

- dry-run 模式自動跳過修復
